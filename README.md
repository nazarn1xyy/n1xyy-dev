# >_ n1xyy.dev | Software Engineer Portfolio

A sleek, minimalistic, and high-performance personal portfolio built for a Software Engineer. The design focuses on a strict black-and-white color palette, eliminating gradients and unnecessary visual noise to achieve a clean engineering aesthetic. 

## Features

- **Strict Minimalist UI:** Built with pure CSS keeping a clean "hacker/terminal" vibe (`var(--bg-main): #000000`).
- **Typographic Identity:** Uses **Source Code Pro** for all elements to maintain an IDE-like reading experience.
- **Micro-Interactions:** Custom JavaScript-powered typing effect (`IntersectionObserver`) and pure vector SVG `Lucide` icons. 
- **Blueprint Grid:** Features a faint geometric 3px linear-gradient grid background for architectural depth.
- **Mobile-First Responsiveness:** Flawless horizontal scrolling constraints, adaptive flex layouts, and a glass-morphic mobile navigation bar.

## Sections

1. **System Output (Hero):** Animated typewriter introduction with a simulated JSON configuration block.
2. **Tech_Stack:** An inventory of backend, database, mobile, and automation proficiencies.
3. **Active_Projects:** A grid displaying real-world system implementations (ranging from high-frequency Crypto Signals to Telegram Automation and iOS Apps).
4. **Initialize_Connection:** A minimal contact terminal utilizing a direct link to Telegram.

## Setup & Deployment

You can run this project locally without any dependencies or build steps.

```bash
# Clone the repository
git clone https://github.com/nazarn1xyy/n1xyy-dev.git

# Navigate to the folder
cd n1xyy-dev

# Run a simple Python built-in server (or any other HTTP server)
python3 -m http.server 3000
```
Then visit `http://localhost:3000` or `http://127.0.0.1:3000` in your browser.
